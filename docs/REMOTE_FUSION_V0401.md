# 双 RTX 2080 Ti 融合 v0.1.40.1（2026-10-07）

引擎基于上游 v0.1.40，服务端包含 v0.1.40.1 热修复（提交
`82f46a8c8f475f001ad76d92f58f4a4f8ffb0253`）。上游重写了历史；本次保留
远端原分支和本机 SSD 扩展的提交历史，部署与推送均不强制覆盖历史。

上游已包含双卡专家交换按所属 GPU 取回权重、跨所有层的热度排序和各卡
权重裁剪。保留新版实现，将实际交换函数抽到 `resident_swap.hpp`，使双卡
回归测试直接调用生产函数。另保留 cache/device 检查、锁页交换缓冲的
`cudaHostAllocPortable`、`--resident-experts-strict` 与 `--stage-weights` 兼容。

正式入口仍为桌面的 Strata IQ3_S，8880 端口、262144 上下文、4096 prefill、
INT8 KV、MTP 4、24+24 层、GPU 视觉、严格 RAM 专家补集与
`fit_max_tokens: true`。按已有用户设置无需 API key。新程序位于
`engine/fusion-v0401`，旧程序和升级前配置保留。部署不启动或重启模型。

自动 SSD 会话缓存位于 Strata 根目录的 `conversation-cache`，上限 32 GiB、
64 份记录，RAM 会话停车预算为 0。分支切换时保存所有 GPU 的完整推理状态；
同一会话正常续接和逐 token 生成不因这个缓存新增 SSD 存取。缓存仅在当前
引擎运行中复用，不跨重启恢复；这与上游显式持久化 slot API 是两种功能。

Linux / CUDA 12.8 / 两张实际 RTX 2080 Ti 上，12 个 C++ 测试目标全部通过：
4259 项 GPU 快照检查（120 项双卡 SSD 恢复检查），60 项 SSD CPU 检查、
185 项会话文件检查、4191 项 RAM 缓存检查、972 项无 GPU 状态校验与
1548 项故障注入检查、23 项内存检查、11 项内存规划检查。
生产交换函数通过 pageable/pinned 两组共 512 次双卡专家交换，权重字节
精确一致，无文件回退。SSD 恢复检查包含 GDN、PLE、索引器、主/草稿 KV、
INT8 scales、草稿环和早期回合检查点。

以上是小型夹具测试。没有加载完整模型，没有测量真实长上下文切换、吞吐、
输出质量或新版本视觉识别能力。此前文档中的模型性能数字不代表本融合版。
