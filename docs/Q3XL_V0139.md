# Q3XL / v0.1.39 双卡更新记录 · 2026-10-05

远端现有 `strata-2080tix2` 分支融合官方 [v0.1.39](https://github.com/Niko1221/Strata/releases/tag/v0.1.39)。上游提交 `6f32ec070f23ced9f50e704d854d775da52591ab`，融合代码提交 `fcb47023c7d588aec78a6c350d466ff288303471`。

机器为两张扩容至 22 GiB 的 RTX 2080 Ti、32 GB RAM、Linux / CUDA 12.8。模型仍为 UD-Q3_K_XL；未修改权重、ngram 或 tokenizer。保留 262144 上下文、INT8 KV、24/24 层划分、4096 prefill、MTP4 和 CPU 视觉。

## 实现与配置

- 保留跨 GPU 的 RAM 专家补集、所属设备上的交换及上传完成同步。
- 保留全局专家热度排序修复：先保存两张卡的共同排序，再划分各卡 profile，避免 RAM 预算只覆盖 CUDA0。
- 分层权重加载改用上游实现，保留 router 供预取；旧 `--stage-weights` 是 `--trim-stage-weights` 的兼容别名。
- 最终使用 `--resident-budget-gib 24`、`STRATA_RESIDENT_HEADROOM_GIB=1`，桌面启动器已同步。这是启动分配的预算余量，并非运行期可用内存的硬下限。
- 实际 RAM 专家约 24 GiB / 11345 个，双卡显存驻留 11786 个。约 3.04 GiB 专家没有固定驻留，依赖文件缓存；并非零 SSD 读取。

## English

Official v0.1.39 is merged into the existing dual-2080-Ti branch. Cross-device resident expert swaps and global RAM-tier ranking remain; duplicate stage weight loading was replaced by upstream trimming. The model and tokenizer are unchanged. The deployment retains 262144 context, INT8 KV, a 24/24 layer split, 4096 prefill, MTP4 and CPU vision.

The selected configuration uses a **24 GiB expert budget and 1 GiB startup headroom**. Around 3.04 GiB of experts remain outside fixed residency and depend on the file cache. Both file reads and system swapping still occur.

Four 1024-token outputs averaged **27.62 tok/s**, versus **21.32 tok/s** for the original configuration: **29.5% faster in this sample**. Individual runs ranged from 26.4 to 29.6 tok/s. The 22 GiB configuration averaged 22.05 tok/s and included a 13.2 tok/s dip. The table above lists every measured output. Available RAM during the final long-output tests stayed at or above approximately 1.10 GiB; startup reached 0.56 GiB.

This compares complete configurations, not isolated upstream kernel changes. Baseline and 22 GiB tests used a private engine; the final 24 GiB tests used the HTTP service with CPU vision loaded. OS caches were not flushed and adaptive placement was not fixed. These short tests do not establish long-term stability or equivalence to IQ3_S benchmarks with different prompts.

GPU swap byte checks, file-source tests, configuration/API checks and production HTTP smoke tests passed. KV reuse was observed, including 3794 of 3801 tokens in the long-prompt test. However, exact greedy output parity failed for that adaptive-placement test; the failure is retained and strict cache parity remains unverified. Full 262144-token inputs, concurrent slots and SSD session storage were not tested or enabled.
