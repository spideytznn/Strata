# 本机融合 v0.1.40.1（2026-10-07）

引擎基于上游 v0.1.40，服务端包含 v0.1.40.1 热修复。上游版本提交为
`82f46a8c8f475f001ad76d92f58f4a4f8ffb0253`。由于上游历史重写，本次使用
v0.1.39 的原基线与本机完整改动进行三方融合，没有重置或覆盖旧开发目录。

保留独立 prefill 缓冲规划、SSD 热专家进入已有冷 RAM 槽、外部 FP8 ngram
与 GGUF 分片兼容、自动 SSD 会话缓存和 Monitor 指标。保持 8880 端口、
262144 上下文、8192 prefill、INT8 KV、MTP 4、33 GiB RAM 请求与 CPU 视觉
16 线程／每张图最多 1024 token。`fit_max_tokens` 继续开启。

新引擎和 CPU 视觉编码器放在 `engine/fusion-v0401`，旧引擎与原 CPU/GPU
视觉程序保留。桌面入口仍是 `Start-Strata-IQ4XS.bat`。部署不停止、启动或
重启模型；已有进程需由用户手动关闭后重新使用桌面脚本，才会应用新版本。

上游的持久化会话保存／恢复 API 已合入，但配置暂未启用。自动 SSD 缓存
仍仅在本次引擎运行中复用，不自动跨重启恢复。为避免未经验证的状态组合，
自动 SSD 缓存与弹性 K/V 不同时开启；本地热专家升级与异步／轮换交换不
同时开启。当前配置没有启用这些新可选项。

GPU 快照夹具通过 4139 项检查，包含自动 SSD、上游会话文件、各 KV 格式
和检查点恢复；SSD CPU 60 项、RAM 缓存 4191 项、快照验证 972 项、内存
检查 25 项、独立内存规划 11 项检查通过。热 RAM 的 pageable／mapped、
不同专家块大小与反复交换的运行测试通过。未启动第二个完整模型，也未测量
真实长上下文速度。旧版本文档中的性能数据不代表这个新融合版的速度。

Windows 兼容修复：上游故障注入夹具显式转换 byte 值；会话目录测试按
实际文件目录身份核对 Windows 8.3 与完整路径别名。Ninja 的 MSVC 头文件
依赖前缀继续根据编译器实际输出修复。
